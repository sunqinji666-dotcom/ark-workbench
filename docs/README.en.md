# Ark Workbench

A local-first image workspace for generation, review, and lightweight creative operations.

![Project visual](docs/assets/ark-workbench-hero-v1.png)

## What it does

A local-first image workspace for generation, review, and lightweight creative operations. It is designed to be understandable, local-first where applicable, and configurable without committing credentials.

## Quick start

Read the project README for the platform-specific command. Keep secrets in environment variables or local configuration files that are ignored by Git.

## Privacy boundary

The public repository contains no personal captures, credentials, tokens, or deployment secrets. Supply your own data locally.
